# CODE 5기 3조 26-1 미니프로젝트

## 주제: 높은 음주율이 반드시 높은 간 수치를 의미할까?

**지역별 GGT(간 수치)와 건강행태의 상관관계 분석**

- **사용 툴:** Python (Pandas, NumPy, Matplotlib, Seaborn) / Google Colab

---

### 분석 데이터
1. **국민건강보험공단 건강검진정보 (2023년, 2024년)**
   - **제공기관:** 국민건강보험공단 (공공데이터포털) / **표본 규모:** 연도별 각 100만 명 무작위 추출 (총 33개 변수)
2. **2024 국민건강통계 (`hn24_all.sas7bdat`)**
   - **제공기관:** 질병관리청 (영양소 섭취량 확장 분석 활용)
3. **시·군·구별 중강도 이상 신체활동 실천율 (2024년)**
   - **제공기관:** KOSIS 국가통계포털 (신체활동 실천율 비교 분석 활용)

- **공통 주요 변수:** 시도코드, 성별코드, 연령대코드, 신장, 체중, 수축기/이완기 혈압, 식전혈당, 감마지티피(GGT), 흡연상태, 음주여부 등

---

### 주요 내용
1. **가설 검증 및 역설 발견**
   - '음주율이 높은 지역일수록 간 건강(GGT)이 안 좋을 것이다'라는 가설로 분석을 시작함.
   - 하지만 분석 결과, 두 연도 모두 음의 상관관계($r = -0.443$)가 나타나는 역설적인 패턴을 확인하고 가설이 기각됨.

2. **원인 심화 및 확장 분석**
   - 단순 음주율 외에 **지역별 고령화 구조, 흡연 동반율, 영양소 섭취량, 유산소 신체활동 실천율** 등 복합적인 생활습관 요인을 다각도로 분석함.
   - 바플롯(Barplot), 산점도, 상관관계 히트맵 등을 활용해 시각화 및 인사이트 도출.
